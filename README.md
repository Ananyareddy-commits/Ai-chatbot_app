# RAG Document Store AI Chatbot

An interactive AI chatbot application built using **Streamlit** and a **Retrieval-Augmented Generation (RAG)** architecture to interact with stored documents.

## Prerequisites

This project requires **Python 3.10.11** installed on your system. 

## How to Run the Application

Because of local system path configurations, the application must be executed by calling the Python interpreter directly. 

Open your terminal in the project directory and run the following command:

```powershell
& "C:\Users\Rakesh\AppData\Local\Programs\Python\Python310\python.exe" -m streamlit run "AI chatbot.py"
```

Once running, the terminal will provide a local URL (usually `http://localhost:8501`). Open this link in your web browser to view and use the chatbot interface.

## Project Structure
* `AI chatbot.py` - The main Streamlit user interface and application logic.
* `README.md` - Documentation and setup instructions.
